এই ফোল্ডারে প্রশ্নের ভিডিও / অডিও রাখুন (QuizCorner_Media)
=========================================================
- এই ফোল্ডারটা কুইজ ফাইলের (Quiz_Corner_V66_FINAL_Broadcast_Engine.html) পাশেই থাকবে।
  লঞ্চার (START_QUIZ_CORNER.bat) না থাকলে নিজে থেকেই ফোল্ডারটা বানিয়ে দেয়।
- ফাইলের নাম: রাউন্ড আর প্রশ্নের নম্বর দিয়ে —
    R1-5.mp4   = রাউন্ড ১, প্রশ্ন ৫-এর ভিডিও
    R3-2.mp3   = রাউন্ড ৩, প্রশ্ন ২-এর অডিও / গান
  (ভিডিও: mp4 / webm • অডিও: mp3 / m4a / wav)
- তারপর কন্ট্রোল প্যানেল > Home > "🎬 Audio / Video" > "🔍 Find the files in the folder" টিপুন — সব প্রশ্নে নিজে বসে যাবে।
  (অথবা প্রশ্নের লাইনে "📁 From the laptop folder" টিপে এই ফোল্ডার থেকে ফাইল বাছুন।)
- ফাইল কপি বা ছোট হয় না: যত বড়, যত লম্বা, যত ভালো মানের — ল্যাপটপ থেকেই সরাসরি চলে।
- টিভিতে: প্রথমে ভিডিও / অডিও পুরো পর্দায় → শেষ হলে (বা Next) প্রশ্ন → তারপর দলের ছবি, টাইমার, উত্তর।
- ফাইলের নাম বদলালে বা সরালে আবার "Find the files in the folder" টিপুন।
